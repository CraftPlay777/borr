# Borr (Area Clearer) - A Luanti (Minetest) Mod

**Borr** is a simple and lightweight administrative tool for Luanti (Minetest) that allows server admins to instantly clear large areas of blocks (nodes), dropped items, and entities using intuitive chat commands.

## Features
- Removes all nodes (turns them into `air`).
- Removes all entities and dropped items in the selected area.
- Ignores players (players inside the area will not be deleted).
- Multilingual support (English, Spanish, and French).

## Permissions
To prevent griefing, players need the `server` privilege to use these commands.

## How to use
1. Stand on the first corner of the area you want to clear.
2. Type `/borr pos1` in the chat.
3. Move to the opposite corner (diagonally, including the height you want to clear).
4. Type `/borr pos2` in the chat. 
5. The area will instantly be replaced with air and cleaned of entities.
